***Assembly***


**Part list**

1x	Mk1 Command Pod
1x	Mk1 Crew Cabin
1x	Probodobodyne HECS
1x	Z-200 Rechargeable Battery Bank
1x	Clamp-o-Tron Docking Port jr.
1x	Heat Shield (1.25m)
3x	OX-STAT Photovoltaic Panels
3x	Basic Fin
3x	Life Support HexCan 0.75m
6x	Stratus-V Minified Monopropellant Tank
4x	Navigation Light Mk1
5x	Surface Mounted Omni Light
2x	Communotron 16-S
2x	RV-105 RCS Thruster block

**Assembly procedure**

Start with the Mk1 pod
Assemble Mk1 cabin axially below Mk1 pod
Assemble HECS axially on top of Mk1 pod
Install Z-200 axially on top of HECS
Install Clamp-o-Tron axially on top of Z-200
Install heat shield axially at bottom of stack
Install Basic fins as finlets on HECS
	3x symmetry with snap
	Facing downwards
	At ventral position (and 120 degrees from ventral)
	Top of finlet barely touching clamp-o-tron
	Yellow stripe half embedded in Z-200
Install radios on Mk1 pod
	Mirror symmetry, 2x with snap
	At sides of flag
	30 degrees to the sides of centre
		Two positions of snap
	White tips embedded in HECS
	Antennas should not project from capsule
Install OX-STAT panels radially on HECS
	3x symmetry with snap
	On dorsal position
	Long side facing finlets
	Top end covers Z-200 battery black part
	Leaves a bit of the HECS panel at the bottom
Install propellant tanks radially on Mk1 Cabin
	6x symmetry with snap
	Dorsal position
	At the joint between the two sections of the cabin
		They should not touch the cabin windows
	Push tanks so that only 1/3 of the tanks are visible as bulges
Install Hexcans on Mk1 Cabin
	3x Symmetry with snap
	Dorsal position
	Immediately after propellant tanks
	Part of hexagonal ends and hardpoint tips extend past start of heat shield
Install navigation lights on Mk1 cabin
	4x symmetry with snap
	45 degrees from ventral
	Light points in direction of travel
	Thin end of teardrop barely touches the heat shield
Install omni lights on HECS
	3x symmetry with snap
	In space left by solar panels
	Half-half between HECS and Pod
	Dorsal position
	One light between each two finlets
Install omni light in Mk1 pod
	1x symmetry with snap
	At the exact centre of the flag
Install omni light in Mk1 cabin
	1x symmetry with snap
	Ventral position
	In the centre of space aft of propellant tanks
	Between Hexcans
Install RCS on Mk1 cabin
	2x symmetry with snap
	Orthogonal 5-horn configuration
	Ventral/Dorsal position
	In clean space above propellant tanks
	Use RCSBA to calibrate exact vertical position
		Calibrate to null torque with two passengers on board and full load
		Clean space above tanks is left for this calibration purpose
	Use actuator toggles to disable pitch/yaw/roll use
