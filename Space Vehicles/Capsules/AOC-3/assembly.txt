AOC-3 assembly instructions

***Variants***

AOC-3 TKL

Where:

	T = TACLS version 
	K = includes kOS core
	L = includes navigation lights

	(missing suffix indicates capability is not present)

***Payload bay assembly***

NOTE: assemblying the payload bay is a technically challenging task. If possible, use pre-assembled bays. If you properly assemble an AOC-3 bay, SAVE YOUR CRAFT!
NOTE: several elements will protrude from the top of the bay. That´s normal.

**Part list**

1x	Service Bay (1.25m)
1x	Z-200 Rechargeable Battery Bank
1x	Experiment Storage Unit
2x	Life Support Hexacan, 0.75m
2x	Stratus-V Roundified Monopropellant Tank
1x	2HOT Thermometer
1x	PresMat Barometer
1x	HG-5 High Gain Antenna
1x	Communotron 16-S
1x	Mystery Goo (TM) Containment Unit
1x	Z-100 Rechargeable Battery Pack
2x	SP-L 1x6 Photovoltaic Panels

**Assembly procedure**

Start with a 1.25m service bay
Install the Z-200 axially on bottom floor of service bay

Install the experiment storage on top of Z-200 battery
	This protrudes from the top, it's not going to be the last thing, so I won't mention it anymore
Install hexacans radially on experiment storage (ESU)

	2x symmetry with snap
	Install on sides 90 degrees of service bay doors
	To simplify things, you can install it on the sides of the ESU protruding from the bay and push it down
	Insert pointy studs into service bay floor

Install Stratus-V tanks radially on ESU
	2x symmetry with snap
	On sides where the bay doors are
	Right in the middle of the payload bay
	Push tanks towards the centre of the bay until they fit when the doors are closed

Install thermometer and barometer
	Radially on top of the Hexacans
	One on each hexacan
	Facing one of the bay doors

From now on, installation of items will cause assymmetries and therefore unwanted torque.

Install HG-5 antenna radially on Z-200
	On the side where the thermometer and barometer are
	45 degree angle from the door side, to the right as seen from the outside towards the bay
	At the bottom of the payload bay
	Antenna pointing up when stowed
	Use side of ESU for alignment
	
Install Communotron 16-S radially on hexacan
	On hexacan opposite to the HG-5	
	On the same side the door covering the HG-5
	At 45 degrees towards the outside of the bay
	Radio unit on top of the service bay
	Antenna should barely pass through service bay floor

Install Z-100 battery radially on monopropellant tank
	The tank OPPOSITE the HG-5 antenna
	At 90 degrees of the payload bay doors
	Move battery bank slightly towards tank and hexacan so that it fits inside the bay with the door closed

Install goo can radially on experiment unit
	Exactly opposite the HG-5 antenna
	Push downwards until bottom of can touches bottom of bay

Install solar panels
	2x symmetry with snap
	On sides of the outside of payload bay
	Panel hinge to the front, doors open to the rear
	Centred on the payload bay

Calibrate bay mass distribution
	Temporarily install a rocket engine at the bottom of the bay (RT-5 Flea is perfect)
	Set RCS Build Aid in engine mode
	Move goo canister to minimise torque induced by engine
	If goo canister ends up not fitting, compensate by moving monopropellant tanks inwards or outwards and redo calibration process
	Try to reach values of 0.001 or 0.002 KNm. Zero would be optimal.
	Once calibration is complete, push Z-100 battery into the payload bay if it's not fitting properly

Verify calibration
	Empty and refill propellant tanks and see how the torque evolves
	There should be no big variations (ideally none), except when the tanks are about to get empty

*** Crew section assembly***


**Part list**

1x	Mk1 Command Pod
1x	Probodobodyne HECS
1x	Clamp-O-Tron Docking Port Jr.
3x	Basic Fin
3x	Communotron 16
1x	Mk12-R Radial Mount Drogue Chute
2x	Mk12-R Radial Mount Parachute
1x	KR-2042 b Scriptable Control System	(K models only)
2x	Navigation Light Mk1
3x	Domelight Mk1

**Assembly procedure**

Start with Mk1 pod
	I like the white pattern for it

Install HECS axially on top of pod

For K models only
	Install KR-2042 on top of Mk1 pod

Install Clamp-o-tron axially on top of HECS
	On top of KR-2042 in K models

Install fins radially on HECS
	These are going to be converted into finlets
	3x symmetry with snap
	Install on underside of pod (opposite hatch)
	Install inverted: wide side UP
	Rotate 15 degrees so that yellow stripe lines up with Mk1 pod
	Push fins into the pod using relative move so that the yellow stripe is partially embedded in capsule
	Move find using absolute move so that end of fin is aligned with end of HECS

Install Communotron 16 on clamp-o-tron
	3x symmetry with snap
	Exactly above the finlets
	Antennas should be barely touching finlets

Adjust finlets
	Back of finlets should be touching Communotron 16 antennas
	Outer part of finlets must align with grey part of antenna
	Red/white parts should project from finlets

Parachute installation is complicated and requires calibration
	Install a rocket at the bottom of the capsule and use RCS Build Aid in engine mode

Install parachutes radially on HECS
	3x symmetry with snap
	Install parachute on HECS branded panel on top of hatch
	Remote parachute on HECS branded panel from symmetry
	Using snap, rotate parachutes 15 degrees to that they line up with pod
	Move parachutes so that
		Start of blue striped areas touch HECS surface
		Start of blue striped areas line up with change of colour in finlets
	Remove hatch side parachute from symmetry and uninstall
	DO NOT TOUCH PARACHUTES AFTER CALIBRATION

Install drogue parachute on HECS on hatch side
	1x symmetry with snap
	Install drogue chute on HECS branded panel on top of hatch
	Using precision move, move drogue chute to cancel as much torque as possible

Adjust parachute parameters
	Main parachutes		0.6/1000/10
	Drogue parachute	0.03/5000/10

Install Domelights
	3x symmetry
	Aft of the finlets
	Bottom part lined up with bottom of hatch

Install navigation lights
	2x symmetry
	In the corrigated bands on the sides of the capsule
	Thicker part of teardrop facing front
	Aft (thinner) part of lamps touching 5th notch in the band counting from behind
	Set port light to red
	Set stbd light to green

*** Final assembly ***

**Part list**

1x	AOC-3 crew section
1x	AOC-3 payload bay
1x	Heat Shield (1.25m)
15x	Place Anywhere 7 Linear RCS Port

**Assembly procedure**

Connect crew section to top of payload bay
	HG-5 antenna should go on the underside of the crew section
	HG-5 should deploy to the lower left section of the capsule (right when seen from under)

Test HG-5 deployment
	Dish should remain stowed inside Mk1 pod when not in use
	Dish should extend without touching payload bay doors when extended
	Dish support should not clip propellant tank
	Antenna should not be visible when stowed
		Sometimes, you can barely see an edge, sometimes not
		Can't do anything about it
	Antenna and antenna support is stowed in recessed bay with protecting doors when stowed
		That's my story and I'm sticking to it!



Test longitudinal balance
	Install an RT-5 at bottom of capsule (on heat shield)
	Check torque values and ensure they do not exceed 0.005 KNm

Install RCS blocks: This is a complex operation that requires calibration

Install side aft thrusters (Linear 7)
	2x symmetry with snap
	On left/right sides of capsule
	As far back as possible
	Rotate 15 degrees so that mass is ejected straight to the sides
	Move inside so that nozzle is flush with capsule
	Using actuation toggles, disable everything except left/right movement

Install side fore thrusters (Linear 7)
	2x symmetry with snap
	On left/right sides of capsule
	One notch (as marked in the side band) behind parachutes
	Rotate 15 degrees so that mass is ejected straight to the sides
	Move inside so that nozzle is flush with capsule
	Using actuation toggles, disable everything except left/right movement

Install up/down aft thrusters (Linear 7)
	2x symmetry with snap
	Top/bottom side of capsule
	Immediately aft of hatch
	Rotate 15 degrees so that mass is ejected straight to the sides
	Using actuation toggles, disable everything except up/down movement
	Move inside so that nozzle is flush with capsule
	Remove from symmetry after installing

Install up fore thruster (Linear 7)
	2x symmetry with snap
	Bottom side of capsule
	Immediately aft of bottom finlet
	Move inside so that nozzle is flush with capsule
	Using actuation toggles, disable everything except up/down movement

Install down fore thruster (Linear 7)
	2x symmetry with snap
	Bottom side of capsule
	Immediately after hatch and before drogue chute
	Move inside so that nozzle is flush with capsule
	Using actuation toggles, disable everything except up/down movement

Install back thruster (Linear 7)
	3x symmetry with snap
	On top of HECS
	In line with parachutes
	Nozzles projecting through clamp-o-tron sides facing forward
	Using actuation toggles, disable everything except fore/back movement	

Install fore thruster (Linear 7)
	4x symmetry with snap
	At bottom of thruster bay on the outside
	At 45 degrees from hatch
	Nozzles should project from heat shield when installed
	Using actuation toggles, disable everything except fore/back movement	
	NOTE: Fore thrusters WILL NOT fire with payload bay closed

Install heat shield axially at the bottom of the service bay
	Beware: connection points may show from hexacans and battery from inside bay
	Make sure you connect shield to the bay
	Test by highlighting battery and seeing that the heat shield DOES NOT light up
	Connection into hexacans leave a grossly skewed shield
		But you can test by highlighting the cans anyway
	Set ablator to 50

Calibrate thrusters
	Select desired propellant level
		One possibility is to select full tanks
	Set RCSBA on translation mode
	Set forward translation
		Torque should already be zero
		Non zero torque indicates a longitudinal imbalance
	Set backwards translation
		Torque should already be zero
		Non zero torque indicates a longitudinal imbalance
	Set left translation
		Derate RCS thrusters on sides to eliminate torque
	Set right translation
		Torque should already be zero or near zero because of left translation calibration
	Set up translation
		Derate RCS thrusters on at bottom to eliminate torque
	Set down translation
		Derate dorsal RCS thrusters to eliminate torque

Isolate life support supplies in Mk1 pod
	Water, Oxygen, Food
	This is going to be the emergency reserve
