AOC-1 Basic capsule

Parts list
1x Mk1 Command Pod
1x Probodobodyne OKTO
1x Heat Shield (1.25m)
1x Mk16 Parachute
2x Communotron 16-S	(for stock capsules)	OR
2x Reflectron DP-10	(for RemoteTech capsules)
1x 2HOT Thermometer
1x PressMat Barometer
1x OX-STAT Photovoltaic Panels


Assembly procedure
Start with Mk1 pod
	Drain all monopropellant
Install heat shield axially on bottom of capsule
	Set ablator to 0
Install computer axially on top of capsule
	Set "Hibernate on warp" to "Auto"
	Set "Hibernate" to "Off"
Install radio antennas radially on OKTO
	Mirror symmetry with snap
	Use first notch for snap (antennas should rest at end of S facing computer panel)
	Rotate so that casing rests solidly on computer (at 0 degrees)
	Move downwards until bottom of casings touch bottom of computer panel
	Antennas should embed into capsule and extend past computer
	Antennas should be parallel to each other
Install parachute axially on top of computer
	Angle 0
	Pressure 0.6
	Altitude 1250
	Deploy Safe
Install barometer and thermometer on capsule sides
	Barometer to left of hatch, thermometer to right
	Direction W/E
	Top of instrument touching seam next to sixth line of notches in white strip
Install solar panel radially on computer
	Direction N
	Centred on OKTO panel
