**Assembly**

Start with engine
Mount OSCAR-B axially on top of engine
Mount second OSCAR-B axially on top of first OSCAR-B
Mount OKTO computer axially on top of stack
Mount cubic strut radially on top of OKTO
	Select anywhere except on axial point
	Move strut on top of axial point using part offset with snap
	Push strut down into computer so that half of it projects over it
	Verify alignment using RCS Build Aid engine mode
Mount parachute axially on top of strut
	Note that we now have 2 axial mount points, one on top of strut and another on top of OKTO
	Use the strut mount point
Install battery axially on OKTO mount point
Install decoupler axially on top of battery
Use move tool to push parachute assembly down into the stack
	Disable snap for precise movement
	Tip should project over battery, but should not project itself over decoupler top end
Install panels radially over OSCAR-B tanks
	4x symmetry with snap
	Over top tank, but as low as possible
	Long side of panels vertically (following direction of thrust)
Install radios radially on battery
	2x symmetry with snap
	Antennas in traverse direction to thrust
	Use battery lightning marks as guides, covering them
