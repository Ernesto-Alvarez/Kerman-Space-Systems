**Ascent data

Install rocket on platform facing the POM tip direction
Enable SAS
Set thorttle to full and activate engines
Initiate pitch over maneuver at max deflection until velocity vector reaches 45 degrees from vertical
As soon as launch course is discerned, correct course with sideways nudges to match POM course at end
	Execute this maneuver as soon as possible to avoid inefficiencies
Once correct course is established, disable SAS
	This should happen before end of POM maneuver
	About 20 degrees from vertical
Eject boosters
	Boosters should eject at about the same time the POM turn is complete
	Booster ejection should take priority before holding prograde (fins can take care of that for now)
Hold prograde
	First stage can hold by itself because of the fins
	Second stage needs active correction. 
		Use manual correction with SAS on block 1 or HECS prograde on block 2.
		If using RemoteTech, set flight computer to surface prograde.
			Switch to orbital prograde at about 38 Km
		Is using block 2, correct inclination by switching between surface and orbital mode in SAS
			This is more expensive than POM nudge correction
			Use this only for very fine adjustments
Eject fairing at 70 Km altitude
	Evaluate reserve dV at this point
	Ensure at least 30 m/s dV is available after payload ejection to return from orbit
		Use reserve dV ratio and post-burn dV to calculate estimated after-release dV
Burn until apoapsis = 100 Km
Circularise at apoapsis
Eject payload and execute retrograde burn to recover booster
