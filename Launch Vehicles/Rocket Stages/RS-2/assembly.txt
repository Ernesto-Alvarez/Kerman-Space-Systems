RS-2 Javelin assembly

****Avionics****

Parts list
1x	Probodobodyne OKTO	(variants A, B and C)	or
1x	Probodobodyne OKTO	(variants D, E and F)
1x	Z-200 Rechargeable Battery pack
1x	Mk16 Parachute

Assembly procedure
Start with OKTO or HECS computer
Install Z-200 battery on axially on top of computer
Install parachute axially on top of battery
Set parachute parameters
	Min pressure	0.35
	Altitude	850
	Spread angle	0

****Final Assembly****

Parts list
1x	avionics subassembly
1x	FL-T400 Fuel Tank
2x	Communotron 16-S
1x	LV-909 "Terrier" Liquido Fuel Engine
1x	Service Bay (1.25m)
1x	TD-12 Decoupler
1x	Fairing type A1 (variants A and D)	or
1x	Fairing type A2 (variants B and E)	or
1x	Fairing type A3 (variants C and F)

Assembly procedure

Start with T400 tank.
	Use dark "checkerboard" pattern.
Install communotron antennas radially on tank.
	2x symmetry with snap
	Antenna should barely touch "rivet ring" panel on top and checkerboard panel (but not checkerboard) at the bottom.
Install LV-909 axially under tank.
Install service bay axially on top of tank.
Install fairing axially on top of service bay.
Install TD-12 decoupler axially in fairing base.
	TD-12 may be replaced by other decouplers or bay assemblies depending on function.
Install avionics subassembly on service bay
	Axially, connected to bottom of bay.
	Parachute should end up in fairing base.
