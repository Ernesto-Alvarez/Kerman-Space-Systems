RS-1 Atlatl Assembly

Notes:
If possible, use prefabricated subassemblies. Assembly instructions indicate precise positioning of elements.

****Fin subassembly****

Part list
4x	AV-8R Winglet
1x	LV-T30 "Reliant" Liquid Fuel Engine
1x	FL-T400 Fuel Tank

Assembly procedure
Select LV-T30 engine as root part. Gas generator exhaust should face western orientation.
Install FL-T400 axially above engine. Use dark "checkerboard" pattern.
Install AV-8R winglets radially over tank using 4x symmetry and snap.
	Orientation should be NE/SE/SW/NW.
	Align fin height by matching second to lowest panel junction (line separating middle of fin) to exactgly the centre of lower tank checkerboard line.
	When aligned, lowest junction should point to end of engine shroud.

****Booster installation****
For E, F and G variants.

E variant uses L-30 400 booster
F variant uses L-31 500 booster
G variant uses L-31 400 booster

Part list

1x	RS-1 fin subassembly
2x	TT-38K Radial Decoupler
2x	L30 or L31 series booster

Assembly procedure
Start with fin subassembly.
Install TT-38K decouplers radially with 2x symmetry and snap.
	Use N/S orientation.
	Lower decoupler joint should fit within white square of top line of checkerboard.
Install boosters radially over decouplers.
	2x symmetry with snap.
	N/S orientation.
	Booster T400 tank lower junction of "rivet line" panel should align with top of decoupler.

****Parachute subassembly****

Part list
1x	FL-T400 Fuel Tank
2x	Mk2-R Radial-Mount Parachute

Assembly procedure
Select fuel tank as root.
	Use dark "checkerboard" or white pattern.
Install parachutes radially on 2x symmetry with snap.
	Parachute orientation should be N/S.
	Parachute tips should touch base of lower junction of rivet line panel on top of stage.

****Final assembly****
Part list

1x	RS-1 fin assembly
		Unboosted for A, B, C and D variants
		Boosted with L30-400 for E variant
		Boosted with L31-500 for F variant
1x	RS-1 parachute assembly
1x	FL-T400 Fuel Tank (for A and B variants)	or
2x	FL-T400 Fuel Tank (for C,D and E variants)	or
3x	FL-T400 Fuel Tank (for F variant)
1x	TD-12 Decoupler

Assembly procedure
Start with fin assembly
Assemble tanks axially over fin assembly
Connect parachute assembly axially over tanks
For E and G variants
	Set booster thrust limited to 72% 
Set fuel tank priority so that tanks drain from bottom to top.
Set Winglet limiter parameters
	Deploy angle	0 degrees
	Authority limit	4 degrees
Set parachute parameters
	Min pressure	0.6
	Altitude	500
	Spread angle	7
