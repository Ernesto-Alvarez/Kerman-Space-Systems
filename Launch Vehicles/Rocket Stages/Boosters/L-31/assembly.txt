L-31 Reliant based liquid fuel booster

Part list

1x	FL-T400 Fuel Tank
1x	FL-T100 Fuel Tank	(L-31 500 only)
1x	LV-T30 "Reliant" Liquid Fuel Engine
1x	Aerodynamic Nose Cone
1x	Cubic Octagonal Strut
1x	Mk16 Parachute

Assembly procedure

Start with T400 tank
Install T100 tank axially on top of T400 tank (L-30 500 only)
Install Reliant engine axially at bottom of tank
	Gas generator exhaust should point WEST
Install cubic strut radially on top of uppermost tank
	Using RCS Build Aid, carefully align strut to ensure no torque is induced when engine is firing
	Strut should be perfectly centered
	Strut should barely project above tank's surface
	Top square should be completely visible
	Vertical elements should barely be visible
Install parachute axially on top of strut
	If done correctly, there should be two axial positions close to each other
	Use the TOP position for the parachute
Install nose cone axially on top of tank
	This should be the BOTTOM position
	Ensure proper fit with tank and exchange positions with parachute if fit is not good
Tank priority should be identical for all tanks
Configure parachute
	Pressure 0.6
	Altitude 1400
	Spread angle 0
