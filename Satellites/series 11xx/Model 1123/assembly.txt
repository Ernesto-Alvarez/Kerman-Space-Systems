Model 1123 assembly

**Parts list**

1x	SpaceBus-1 computer unit
3x	SpaceBus-1 type 1 power unit
1x	SpaceBus-1 type 2 power unit
1x	SpaceBus-1 type 1 propulsion unit
14x	Z-100 Rechargeable Battery Bank
1x	Clamp-o-Tron Docking Port Jr.		(for model C only)
1x	JS-1 Joint Socket			(for model K only)

**Assembly procedure**

**Body assembly**

Start with with SpaceBus-1 computer unit
Install type 1 power unit axially below computer unit
	Solar panels aligned with omni antennas
	30 degrees of angle respect to hard point 1
Install type 2 power unit axially below stack
	Panels aligned with hardpoint 1
	Below OKTO brand tag
	Where HG-5 antennas will be
Install type 1 power unit axially below stack
	Same alignment as power unit type 2
	Panel aligned with hardpoint 1
Install type 1 power unit axially below stack
	Same alignment as topmost power unit
Install propulsion unit below stack

*Final modifications*

Install Z-100 batteries on propulsion unit
	8x symmetry with snap
	Battery light pointed towards engine
	Side with no light aligned with top of OSCAR-B tank

Install Z-100 batteries on type 2 power unit
	3x symmetry with snap
	Light pointed to computer unit
	Bottom of battery bank matching bottom of black zone in lower Z-200
	Install in free space between antennas

Install HG-5 radios on computer unit
	3x symmetry with snap
	On hardpoint 1 and symmetry points
	Antennas should occupy hardpoints 1, 4 and 6
	Arm pointed downwards when stowed
	Antenna deploys outwards and ends perpendicular to onmi antennas and longitudinal axis of the vehicle	

Install Z-100 batteries on computer unit
	3x symmetry with snap
	Install on hardpoint 2
	Top of Z-100 aligned with top of OKTO

Correct orientation of Z-100 batteries on OKTO
	Remove from symmetry
	Rotate so that batteries are at same angle as hardpoint
	Move so that batteries are in centre of hardpoint
	Batteries should occupy hardpoints 2, 3 and 5
	Opposite HG-5 radios

Install attachment point
	JS-1 socket for model K
	Clamp-o-tron jr. for model C
