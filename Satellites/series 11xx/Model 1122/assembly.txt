Model 1122 assembly

**Parts list**

1x	SpaceBus-1 computer unit
2x	SpaceBus-1 type 1 power unit
1x	SpaceBus-1 type 1 propulsion unit
10x	Z-100 Rechargeable Battery Pack
2x	HG-5 High Gain Antenna
2x	Z-200 Rechargeable Battery Bank
2x	OX-STAT Photovoltaic panels
1x	Clamp-o-Tron Docking Port Jr.		(for model C only)
1x	JS-1 Joint Socket			(for model K only)

**Assembly procedure**

*Creation of custom section*

Start with Z-200 bank
Mount Z-200 bank on top of Z-200 bank axially
Install OX-STAT panels radially on top Z-200
	2x Symmetry with snap
	As low as possible within top Z-200
	N/S direction
	Push panels inward, as close as possible without them clipping or showing through panel
	Long side vertical
Install extra Z-100 batteries radially
	2x Symmetry with snap
	Bottom of Z-100 at bottom of black part of lower Z-200
	E/W direction

*Modification of computer unit*
Install HG-5 radially on sides of OKTO
	2x symmetry with snap
	Antenna support at the top of the hardpoints 1 and 2 on the OKTO
	Arm pointed downwards when stowed
	Antenna deploys outwards and ends perpendicular to onmi antennas and longitudinal axis of the vehicle

*Final assembly*
Start with computer unit

Install power unit below computer, axially
	Solar panel oriented with HP 1 and 2
	All others at an angle

Install custom unit below power unit, axially
	Solar panels oriented with HP 1 and 2
	HG-5 antennas should rest on top of solar panels, without touching them

Install second power unit below custom unit, axially
	Rotate unit (or panels), so that two panels point in the same direction as the onmi antennas
	Panels should be shifted by 30 degrees compared to other power unit

Install propulsion unit below stack, axially

Install Z-100 batteries on propulsion unit
	8x symmetry with snap
	Battery light pointed towards engine
	Side with no light aligned with top of OSCAR-B tank

Install connector axially on top of computer (models C and K only)
