Model 1302 assembly

**Parts list**

1x	SpaceBus-1 computer unit
2x	SpaceBus-1 type 2 power unit
1x	SpaceBus-1 type 2 propulsion unit
1x	2HOT Thermometer
1x	Pressmat Barometer
8x	Mystery Goo (TM) Containment Unit
1x	Experiment Storage Unit
1x	Mk16 Parachute

**Assembly procedure**

*Final assembly*
Start with computer unit

Install power unit below computer, axially
	Solar panel oriented with HP 1
	All others at an angle

Install propulsion unit below stack, axially

Install thermometer on HP1
	Radially
	Centre of hardpoint

Install thermometer on HP2
	Radially
	Centre of hardpoint

Install goo capsules radially on propulsion unit
	On lower OSCAR-B tank
	As high as possible
	8x symmetry with snap
	In same position as HP 1 and 2

Install storage unit axially over OKTO computer

Install parachute axially on top of storage unit

Re-root to experiment storage unit
