Model 1302 temperature/pressure/goo data return probe

***Description***

The model 1302 is a data return sensor/goo probe. The probe has only short range comms and follows a launch-flyby-return profile. Science is gathered during flyby by using the RemoteTech flight computer to trigger experiments. Once the data is captured, the probe returns to Kerbin and burns in the atmosphere, with the experiment storage unit landing on Kerbin's surface via parachute.
