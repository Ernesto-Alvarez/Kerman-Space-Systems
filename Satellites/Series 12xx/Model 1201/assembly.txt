Model 1201 assembly

**Parts list**

1x	SpaceBus-1 computer unit
2x	SpaceBus-1 type 1 power unit
1x	SpaceBus-1 type 1 propulsion unit
2x	Z-100 Rechargeable Battery Pack
6x	OX-STAT Photovoltaic panels
1x	R-3B Radar Altimeter

**Assembly procedure**

*Final assembly*
Start with computer unit

Install power unit below computer, axially
	Solar panel oriented with HP 1 and 2
	All others at an angle

Install second power unit below stack, axially
	Rotate unit (or panels), so that two panels point in the same direction as the onmi antennas
	Panels should be shifted by 30 degrees compared to other power unit

Install propulsion unit below stack, axially

Install OX-STAT panels on propulsion unit
	6x symmetry with stack
	In the centre of the OSCAR-B tank
	Offset panels 15 degrees towards HP5

Install extra batteries radially on OKTO
	Hardpoints 1 and 2
	Centre on OKTO panels

Install radar antenna on top of OKTO
	Antenna install radially. If possible, use axial mount
	Use move tool with clip to centre antenna on computer
	Use RCS Build Aid to ensure that antenna does not produce torque when propelling
	Push antenna down (without snap) to ensure that antenna mount touches computer
