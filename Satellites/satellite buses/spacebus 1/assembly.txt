SpaceBus-1 Assembly

***Computer unit***

**Parts list**

1x	Probodobodyne OKTO
2x	Communotron 16

**Assembly procedure**

Start with OKTO
Install C16 radially on OKTO
	2x symmetry with snap
	Facing E/W
	In the middle of the panel

***Power unit***

**Parts list**

2x	Z-200 Rechargeable Battery Bank
6x	OX-STAT Photovoltaic Panels		OR	(for type 1)
3x	OX-STAT Photovoltaic Panels		OR	(for type 2)
4x	OX-STAT Photovoltaic Panels			(for type 3)

**Assembly**

Start with Z-200
Install Z-200 axially at bottom of Z-200
Install panels radially on top Z-200
	As low as possible while attaching to top Z-200
	With snap
	6x (type 1), 3x (type 2) or 4x (type 3) symmetry
	Install facing N (not critical, just as reference)
For types 2 and 3, move panels closer to Z-200
	No snap
	Move tool to absolute mode
	Push until panel rests on battery, but battery MUST NOT show through panel

***Propulsion unit***

**Parts list**

1x	LV-1 "Ant" Liquid Fuel Engine
1x	OSCAR-B fuel tank			OR	(for type 1)
2x	OSCAR-B fuel tank				(for type 2)

**Assembly**
Start with OSCAR-B tank
Install engine axially below tank
For type 2, install second tank on top of OSCAR-B
